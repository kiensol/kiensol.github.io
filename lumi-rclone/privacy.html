Privacy Policy for lumi-rclone

Effective date: November 23, 2026

Overview

lumi-rclone is a personal application used by a single user (its owner) together with the rclone command-line tool, to access the owner's own Google Drive from the owner's own computer.

Data collection

The application does not collect, store, transmit, sell, or share any personal data on any server. There is no server component to this application.

How data flows

Files are transferred directly between the owner's computer and Google Drive through Google's APIs, only at the owner's direction. OAuth access tokens are stored only locally on the owner's computer, in rclone's configuration file.

Google user data

Google user data is accessed solely to list, upload, and download the owner's own files in the owner's own Google Drive. It is never shared with third parties.
